# 简体中文写作规范

简体中文从英文翻译，意思以英文为准。

## 名称

- 顺序是"器械＋姿势或变化＋动作"：哑铃上斜卧推、杠铃罗马尼亚硬拉、绳索坐姿划船、哑铃单臂划船。
- 徒手动作不加器械名：俯卧撑、引体向上、平板支撑。不加会说不清时才写"自重"，比如自重深蹲。
- 器械、姿势和动作统一用下面的术语表。表里没有的，用国内健身房最常用的叫法。
- 组合动作用"接"连起来：哑铃弓步接弯举。
- 名称里不用括号、版本号、性别、拍摄视角，也不用连字符。
- 同一种语言里，名称不能重复。

## 别名

- 中文里真实在用的其他叫法，比如杠铃卧推的"平板卧推"、蝴蝶机夹胸的"夹胸"。
- 别名不必是英文别名的翻译，也不能是另一个动作的名称或别名。

## 步骤和要点

- 每一步是一句完整的祈使句，句号结尾，不用"你"开头。
- 意思和英文一致，句子按中文习惯写，不逐词硬译。
- 用全角标点。中文和英文、数字之间加一个空格：45 度、EZ 曲杆。
- 不写组数、次数、重量和时间。
